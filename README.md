# ChronaLab

**ChronaLab** is a modular and open-source toolkit for sharing time-series analysis methods and make benchmarks.

It provides a simple yet powerful framework for analysing, visualising, and understanding time-dependent behaviours in embedded systems, signals, and other dynamic environments.
